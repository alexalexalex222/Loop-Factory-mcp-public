## Frozen Architecture Decisions

1. Loop Factory's deterministic verifier remains the only credit and activation
   authority.
2. Research, retrieval, reranking, falsification, and candidate generators may
   propose context or artifacts but cannot promote them.
3. Retrieval begins with a deterministic integrity/compatibility/quarantine
   filter. A model may rerank only the surviving pool.
4. Positive and negative precedents are both first-class retrieval targets.
5. Evaluator workers receive fresh state, anonymous arms, fixed rubric/tool
   contracts, and no proposal/research/lineage history.
6. Replicates reduce noise within a task; task clusters are the inference unit.
7. PACE-style wealth is one gate inside replicated V2, not a replacement for
   placebo, regression, token-cost, untouched confirmation, or familywise gates.
8. Each attribution experiment changes one primary component. Consolidation is
   a separately declared experiment with fresh replay.
9. Final sealed tasks remain outside implementation, research, proposer, and
   reranker contexts.
10. Code-level candidates remain disabled by default, disposable, task-agnostic,
    component-scoped, and unable to edit protected surfaces.

## Ablation Order

```text
B0 current frozen Loop Factory
B1 evaluator isolation only
B2 pre-hypothesis research only
B3 independent falsification only
B4 hybrid retrieval only
B5a GEPA-style reflective generator
B5b SkillOpt-style bounded skill generator
B5c HarnessBank-style recombination generator
B6 independently supported components combined
B7 experimental code-level generator
```

All arms use matched models, tasks, tool contracts, retries, call budgets, and
runtime authority. Development and validation data may guide selection. The
final sealed benchmark is opened once after source, prompts, evaluator,
statistics, model, and candidate budget are frozen.
