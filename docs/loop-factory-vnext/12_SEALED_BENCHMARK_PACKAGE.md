# Sealed Benchmark Package

Historical plan-only release location:
`proof/vnext-sealed-benchmark-package/`

The public repository does not ship that private proof home. Any future release
package must be regenerated from the final public source bytes and a fresh
counterbalanced semantic-judge security qualification. The qualification is a
non-causal safety check, not a B1 performance arm.

Machine-readable authorities:

- `BENCHMARK_MANIFEST.json`
- `CONTEXT_BOUNDARY_TESTS.json`
- `SLING_INTEGRATION_MANIFEST.json` only when a fresh Sling root is supplied
- `ABLATION_MATRIX.csv`
- `SOURCE_AND_ARTIFACT_HASHES.sha256`

`FILES.sha256` verifies the package itself. The Sling manifest binds the exact
isolated integration source, focused tests, production build, browser receipt,
screenshots, loopback bootstrap probe, and final fixture-only restrictive state.

The plan-only package contains no final task, answer, oracle, or
evaluator-hidden bytes. A future protocol-r6 release must freeze the exact
ablation protocol and complete two-form semantic-judge qualification bundle.

It is not the runnable final custodian capsule. That capsule is created by
`npm run vnext:custodian:build` only after one B6 validation candidate passes
the exact-candidate P4 transfer study.

## Required Order

1. Pass local verification and the hosted Windows/Linux/macOS workflow.
2. Generate, separately approve, and independently verify the two-form
   counterbalanced semantic-judge security qualification.
3. Build a fresh protocol from those exact source and qualification bytes.
4. Freeze P0 B0/B2/B3 with `vnext:matched:plan`; approve and run each child
   disclosure separately.
5. Repeat for P1 B3/B4 and P2 B5a/B5b/B5c using one verifier-bank snapshot per
   phase.
6. Select one eligible B5 strategy using the preregistered rule and run one B6
   on the untouched validation pack.
7. Run P4 on the disjoint transfer pack with that exact frozen B6 candidate.
   P4 has no proposer, research, retrieval, or candidate-generation calls.
8. If and only if P4 is a valid causal pass, build the custodian capsule.
9. The external custodian creates one new 10-cluster `final` pack and runs the
   exact frozen candidate once.

## Frozen Final Exposure

- model: exact `gpt-5.6-sol`, reasoning `high`, ChatGPT OAuth;
- arms: candidate, cold, parent, sham;
- clusters: five calibration plus five untouched confirmation;
- replicates: three per arm;
- calls: 60 calibration plus 60 conditional confirmation, 120 maximum;
- per-call ledger reservation: 32,000 input and 8,000 output tokens;
- aggregate ledger ceiling: 4,800,000 tokens;
- sequential timeout ceiling: 1,200 minutes;
- retries and fallback models: zero;
- metered USD ceiling: zero under subscription OAuth;
- promotion, catalog import, evidence-bank import, and activation authority:
  disabled.

Before final execution the custodian must freeze:

- source and implementation hashes;
- final task-pack and oracle-separation hashes;
- exact GPT/Codex route and reasoning effort;
- evaluator prompt, rubric, schema, binary, and disabled features;
- the successful validation and transfer proof hashes;
- the exact already-frozen candidate family, program, and evolution hashes;
- zero retries and no fallback model;
- task-cluster statistical and sham/regression/cost rules;
- the 120-call, 4,800,000-token, 1,200-minute, and zero-USD exposure;
- promotion disabled.

The implementation agent and its subagents never receive the final pack. The
custodian opens it once after every other byte is frozen, runs the exact printed
command, and returns the redacted verifier receipt plus package manifest hash.
The full local plan remains on the custodian machine for replay. This repository
does not claim a final sealed result.
