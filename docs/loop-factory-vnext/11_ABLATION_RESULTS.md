## What Is Proven

- authority boundaries fail closed;
- chronology and partition relabeling are blocked;
- fixtures cannot enter production memory;
- evaluator contexts are isolated under the tested process contract;
- external discovery is browser-only, host-allowlisted, hard-budgeted, and
  separate from deterministic DNS/TLS/byte capture;
- ten current primary paper pages replay from 439,422 exact bytes under evidence
  SHA-256
  `24f9f642e0b65a5b1eece62690c06afef06271e45f3f79a68a2bb6ca0a5bc8fc`;
- candidate targets are exact-locator bound;
- the four non-native strategies enforce different chronological, bounded-skill,
  donor-lineage, and source-worktree semantics rather than sharing only a label;
- code candidates run in detached network-denied worktrees and preserve exact
  input, sandbox, argv, patch, test-log, and replay hashes;
- task clusters, not replicates, drive inference;
- leases, budgets, operator revisions, and no-promotion state replay;
- P0-P3 arms can be frozen in one matched-phase receipt before any child
  launches, proving identical pack, materials, evidence snapshot, parent,
  timestamp, model, evaluator, memory ledger, and implementation;
- P4 evaluates the exact B6 validation candidate without research, retrieval,
  hypothesis revision, or candidate regeneration;
- final evaluation requires a successful exact-candidate P4 prerequisite and a
  new external-custodian pack with zero internal identity-digest collisions;
- the custodian verifier returns aggregate gates and hashes without returning
  final task or oracle bytes;
- Sling exposes restrictive controls without holding the Loop decision token in
  browser code.

## What Is Not Proven

No matched live campaign has yet shown that B2-B6 improve quality, cost,
transfer, or candidate success over B0. The two-form semantic-judge security
qualification has not run and has no causal scoring authority. No
exact-candidate transfer or final sealed benchmark was exposed or run. A valid
FAIL from any later stage remains evidence, not permission to change the gate.
